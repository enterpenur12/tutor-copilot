# Tutor Copilot

Tutor Copilot is an AI-powered writing feedback platform designed to help students improve their essays through rubric-based analysis and personalized revision guidance.

## Overview

Many students struggle to receive timely and detailed writing feedback due to limited teacher time and resources. Tutor Copilot helps bridge this gap by providing instant, actionable feedback while encouraging students to revise and improve their own work.

Unlike AI tools that generate essays, Tutor Copilot focuses on strengthening student writing skills through guided revision.

## Features

* AI-powered essay analysis
* Rubric-based feedback
* Personalized revision suggestions
* Writing improvement guidance
* Support for iterative drafting and revision

## Running Locally

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

## Environment Variables

Create a `.env` file and provide the required API keys:

```env
OPENAI_API_KEY=your_api_key_here
```

## Impact

Tutor Copilot was developed to support student writing improvement and has been piloted with learners through SEA Literacy, a nonprofit serving refugee and multilingual students.

The platform has analyzed over 800 student essays and aims to make high-quality writing feedback more accessible to learners everywhere.
